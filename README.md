# XLuke44's MeeCreeps

Remaster of [McJty's MeeCreeps Mod](<https://modrinth.com/mod/meecreeps>) with new content, bugfixes, improvements and various quality-of-life features.

## Default Controls

### Portal Gun

| Key         | Action                          |
| ----------- | ------------------------------- |
| `R`         | Toggle air placement            |
| `J`         | Close all portals               |
| `L`         | Fast return                     |
| `X`         | Favourite destinations          |
| `Insert`    | Custom destinations             |
| `Q`         | Saved destinations              |
| `C`         | Toggle automatic portal closing |
| `M`         | Switch Portal Gun mode          |
| `Shift + /` | List available dimensions       |

### Creep Cube

| Key                  | Action                          |
| -------------------- | ------------------------------- |
| `Left-click`         | Select a task                   |
| `Shift + Left-click` | Place or pick up the Creep Cube |
| `Right-click`        | Repeat the last task            |
| `J`                  | Despawn all summoned MeeCreeps  |
